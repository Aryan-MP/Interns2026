## DNS Record Type

| Type      | Full Name                             | Purpose                                          |
| --------- | ------------------------------------- | ------------------------------------------------ |
| **A**     | Address Record                        | Maps a domain to an IPv4 address                 |
| **AAAA**  | IPv6 Address Record                   | Maps a domain to an IPv6 address                 |
| **CNAME** | Canonical Name Record                 | Alias of one domain to another                   |
| **MX**    | Mail Exchange Record                  | Specifies mail servers for a domain              |
| **TXT**   | Text Record                           | Stores text data (SPF, DKIM, verification, etc.) |
| **SOA**   | Start of Authority                    | Contains administrative info about the DNS zone  |
| **CAA**   | Certification Authority Authorization | Specifies allowed certificate authorities        |
