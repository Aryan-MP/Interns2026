Task 1:
To use arm template to deploy a VM and use Custom Script Extension CSE to install IIS server.
Conclusion:
The server was installed by using included deployvm.json template on local machine and verified by the VM ip address.

Task 2:
To create a storage account through arm template.
Conclusion:
A storage account was created by using storage.json through powershell on local machine.

Task 3:
To create managed disk inside before created storage account and attach it to VM through Arm template.
Conclusion:
Managed disk and created and attached to VM named WindowsARM by using attachdisk.json template through local machine.

Task 4:
To create arm template to deploy container instance with nginx server.
Conclusion:
container instance was deployed by using azuredeploy.json and verified on azure portal and by accessing web server through container ip address.

Task 5:
To create a Azure container repository ACR through ARM templates.
Conclusion:
A container repository was created by using acrarm.json template on local machine.
