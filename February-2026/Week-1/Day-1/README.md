# Day 1 – Cloud Basic Concepts (Foundation)

## Author
Manoj Gowda

## Session Type
Theory / Conceptual Training

## Topics Covered

### Cloud Computing Fundamentals
- What is Cloud Computing
- Why Cloud is needed
- On-Premise vs Cloud Computing

### Cloud Characteristics
- On-demand self-service
- Broad network access
- Resource pooling
- Rapid elasticity
- Measured service

### Cloud Service Models
- Infrastructure as a Service (IaaS)
- Platform as a Service (PaaS)
- Software as a Service (SaaS)

### Cloud Deployment Models
- Public Cloud
- Private Cloud
- Hybrid Cloud

### Cloud Infrastructure Concepts
- Regions
- Availability Zones
- Datacenters

### Shared Responsibility Model
- Responsibilities of Cloud Provider
- Responsibilities of Customer

### Pricing Concepts
- Pay-as-you-go model
- Capital Expenditure (CapEx) vs Operational Expenditure (OpEx)

## Hands-On
❌ No hands-on task  
This session focused on building a strong conceptual foundation.

## Outcome
- Understood why cloud computing exists and its advantages over on-premise infrastructure
- Able to explain cloud concepts to a non-technical person
- Established a strong base for learning Microsoft Azure
