☁️ 2. Introduction to Compute Engine
In Google Cloud Platform, Compute Engine is an Infrastructure as a Service (IaaS) offering that allows users to create and manage virtual machines (VMs) on Google’s infrastructure.
It provides high flexibility, scalability, and control over computing resources.

🔍 What is Compute Engine?
Compute Engine enables users to:
Launch virtual machines on demand
Select CPU, memory, and storage configurations
Run applications just like on a physical server

⚙️ Key Components
1. Virtual Machine Instances
Core resource of Compute Engine
Runs operating systems like Linux or Windows
Fully customizable
2. Machine Types
Predefined or custom configurations
Options include:
General-purpose
Compute-optimized
Memory-optimized
3. Persistent Disks
Storage attached to VM instances
Data remains even after VM shutdown
4. Networking
Uses Virtual Private Cloud (VPC)
Assigns internal and external IPs
Firewall rules control traffic

🔧 4. Features of Compute Engine
Custom Machine Types → Choose CPU & RAM as needed
Live Migration → VMs move automatically during maintenance
Auto Scaling → Scale resources based on demand
High Availability → Multiple zones and regions
Snapshots & Backups → Data protection
Preemptible VMs → Low-cost temporary instances
