# Day 2 - Training

## Azure Entra ID Roles and Azure RBAC Access Control

On Day 2 of my internship at Spektra Systems, we learned about Azure identity and access management, focusing on Azure Entra ID tenant-level roles such as Global Administrator, and Azure RBAC subscription-level roles including Owner, Contributor, and Reader. We understood how these roles differ in scope and permissions and also had a brief overview on the Azure Portal.
