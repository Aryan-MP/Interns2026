# Day 6 - Assignment

## Task - 1 Custom VM Image & VM Scale Set Deployment

## Created a customized Virtual Machine, capture a specialized image from it, and deploy a Virtual Machine Scale Set (VMSS) using that image.

## Task Workflow
### 1. Virtual Machine Deployment
Deployed a Virtual Machine
Configured required networking and authentication
Ensured successful login and system access

### 2. Software Installation
Installed any two required packages inside the VM, such as:
Python
Google Chrome
Node.js
Validated successful installation and functionality before proceeding.

### 3. Specialized Image Creation
Deallocated the VM
Captured a Specialized Image
Preserved:
Installed software
System configurations
Machine-specific settings
Ensured the image was stored and available for reuse.

### 4. Virtual Machine Scale Set (VMSS) Deployment
Created a VM Scale Set using the specialized image
Configured instance count and scaling settings
Verified that deployed instances contained the pre-installed software
Key Concepts Applied
Custom VM configuration
Image-based infrastructure replication

Specialized image behavior

Scale-out deployment using VMSS
