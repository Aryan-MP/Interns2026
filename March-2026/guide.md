# Lab 01: Open an Existing Virtual Machine in Azure

## Lab overview

The Azure portal provides a centralized interface to manage and monitor Azure resources, including virtual machines. Administrators and users can quickly locate and access existing virtual machines using the search functionality in the Azure portal.

In this lab, you will learn how to access the Azure portal, locate an existing virtual machine using the global search bar, and open the virtual machine resource. You will also explore how to initiate a connection to the virtual machine from the Azure portal.

## Lab objectives

By the end of this lab, you will be able to:

- Task 1: Access and locate an existing Virtual machine in the Azure portal  
- Task 2: Initiate a connection to the Virtual machine

### Task 1: Locate an Existing Virtual Machine

In this task, you will open the Azure portal and use the search feature to locate an existing Virtual machine.

1. Open the **Azure portal (1)** by navigating to the following URL: https://portal.azure.com.

   ![](screenshots/step-01.png)

2. In the Azure portal, click on the **Search resources, services, and docs (1)** search bar at the top, type **Virtual machines (2)**, and select **Virtual machines (3)** under **Services**.

   ![](screenshots/step-02.png)

3. On the **Virtual machines** page, locate and click on the Virtual machine named **rdp (1)** from the list.

   ![](screenshots/step-03.png)

### Task 2: Connect to the Virtual Machine

In this task, you will open the selected Virtual machine and initiate a connection from the Azure portal.

1. On the **rdp Virtual machine** overview page, click on **Connect (1)** to view the available connection options.

   ![](screenshots/step-04.png)

### Summary

In this lab, you accessed the Azure portal and used the global search feature to locate the **Virtual machines** service. You opened an existing Virtual machine named **rdp** and initiated the process to connect to it from the Azure portal. This process is commonly used by administrators to manage and remotely access Azure virtual machines.
