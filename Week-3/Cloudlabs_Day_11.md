☁️ CloudLabs by Spektra Systems 
📌 Overview

CloudLabs by Spektra Systems is a cloud-based virtual lab platform that provides preconfigured environments for hands-on practice of real IT and cloud technologies.

It allows users to perform practical exercises on platforms like Microsoft Azure, AWS, and Google Cloud without installing software or maintaining hardware.

This repository documents the labs completed using CloudLabs, including deployment tasks, configurations, and outcomes.
