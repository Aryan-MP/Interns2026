🧩 What is CloudLabs?

Real-world cloud scenarios
Guided exercises for AWS, Azure, and GCP
Sandbox environments for practice

It is mainly used for:

Skill development
Training and certification preparation
Simulated real-world cloud projects

📦 GCP Asset Inventory
🔍 What is Asset Inventory?

GCP Asset Inventory is a service that:

Maintains a real-time inventory of all cloud resources
Helps in tracking and managing assets across projects
📌 Key Features
View all resources (VMs, buckets, IAM policies)
Track resource history
Search and filter assets
Useful for security and compliance
🛠️ Use Cases
Security auditing
Resource tracking
Compliance monitoring
Troubleshooting
📊 GCP Quotas
🔍 What are Quotas?

Quotas are limits set by GCP on resource usage to:

Prevent overuse
Control billing
Ensure fair usage
📌 Types of Quotas
Compute Quotas
Number of VM instances
CPUs per region
Storage Quotas
Bucket storage limits
API Request Quotas
Number of API calls per minute
⚠️ Key Points
Quotas are applied per project
Can be increased by requesting GCP
Important for cost management and scalability planning
